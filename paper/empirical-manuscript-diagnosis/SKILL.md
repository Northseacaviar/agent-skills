# 实证稿体检

给一篇实证稿下判断：能不能发、能发到哪一档、投稿前必改什么。不是润色，是**在润色之前**决定这篇稿子值不值得改、往哪个方向改。

## When to Use

- 用户问「我这篇能投什么刊」「这篇质量怎么样」「还有发的价值吗」。
- 第一次投稿，需要把目标从「发好刊」改成「能中」，重新定位。
- 拿到审稿意见，需要判断哪些是硬伤、哪些只是口味。
- 改稿前后各跑一次，比较结论有没有实质变化。

不适用：纯语言润色（用 `humanizer`）、AI 痕迹审查（用 `academic-ai-trace-audit`）、宏观 claim architecture 重构（用 `manuscript-optimizer`）。

## 五问闸门

按顺序问，前四问答不出来就别谈投稿策略。

1. **问题是不是真 gap？** 很多「研究空白」是把别人做过的东西换个包装。看它引的最接近的三篇，本文比它们多做了什么。
2. **凭什么说是因果？** 看识别策略：RCT / DID / RDD / IV / 只有回归加固定效应。**只有固定效应的，基本是相关性**，写得再漂亮也只能说「相关」。
3. **如果识别不成立，还剩什么？** 有的稿子识别塌了但描述性事实还有价值（样本构造、测量误差、分布特征），有的塌了就什么都不剩。这一问把「方法有瑕疵的好论文」和「什么都没说的论文」分开。
4. **比最接近的那篇多了什么？** 一句话能不能说清。说不清就是没有增量。
5. **数据和代码给不给？** 不给的，结论只能当参考。

第 2 问决定上限：**期刊档次基本由识别策略的干净程度决定**，不由写作质量决定。

## 拿期刊实物标定，别凭感觉说水平

用户问「我这篇跟要投的刊比，水平够不够」时，唯一可检验的答法是：**下载目标刊最近一整期的全文，用同一套指标量双方**。凭印象说「问题设计不错但执行不够」是空话，给出数字才算判断。

七个指标一次抽完（pymupdf 抽文本，正则在 Python 里跑）：

| 指标 | 抽取法 |
|---|---|
| 正文字符（去空白） | `len(re.sub(r"\s+","",txt))` |
| 页数 | `doc.page_count` |
| 表格数 | `len(set(re.findall(r"表\s*\d+", flat)))` |
| 图数 | `len(set(re.findall(r"图\s*\d+", flat)))` |
| 参考文献条数 | 取最大编号：`max(int(x) for x in re.findall(r"\[(\d{1,3})\]", flat))`。**不要数出现次数**——正文里每条文献被引 1—3 次，数出来是条数的两倍多（会把中位 38 量成 79）；再拿 `flat.find("参考文献")` 之后的文本单算一次最大号，两值相等才敢用。部分刊用脚注制会 0 命中，要另判 |
| 回归观测数 | `re.findall(r"(?:样本|观测值)[^。]{0,12}?(\d{2,6})", flat)` |
| 方法词频 | `flat.count(k)`，k 取 双重差分／DID／工具变量／倾向得分／事件研究／固定效应／安慰剂／Heckman |

量自己的稿子要**先去掉 markdown 符号**（`|`、`#`、`*`）再比字符数，否则表格竖线会把字数撑高两三成，得出虚假的「篇幅达标」。

**但判断超没超，最终看汉字，不看字符。** 表格多、英文文献多的稿子字符／汉字比高（实测 1.27—2.17，中位 1.72）。两篇字符数相同的稿子，表格密的那篇正文可能反而短。给的区间与中位都按汉字报；字符数只用来估版面页数。

**稿子超长时，先量参考文献占比再动正文。** 六七十条文献常占全文 25%—30%，平均每条 130 字符上下；把文献从 68 压到 48 就能减掉两千多字符，而删论证要掉一层证据。压文献是成本最低的超长处理。

**判读分两层，不要混成一句话**：

- **问题设计层**：章节结构、假设写法、自我限定的克制程度。这一层达标就直说达标——很多刊文的这一层反而不如稿子。
- **执行规模层**：观测数、处理组、表格密度、文献密度。这一层差一个数量级时，**它就是决定生死的那层**，写作质量救不回来。

两句结论分开给。合并成「整体不错但有提升空间」等于没有判断。

**最该量的是处理组，不是总样本。** 三万个观测但处理组几百，与 342 个观测、处理组 15 条，差的是两个数量级；审稿人先看后者。

## 结构自检

八段是否各司其职（摘要五句五层、引言说清 gap、文献综述找问题、方法三层、数据含预处理、Results 只写重要结果、Discussion 做成因分析、结论是抽象不是复述）。

三条最容易混的区分：

- **scope ≠ limitation**。scope 内结论必须站得住；limitation 是即使守住 scope，数据和方法仍有边界。常见错误是把 scope 写成 limitation——结论里说个大命题，末尾用「样本有限」兜底。正确做法反过来：scope 收窄到数据够得着的地方，在范围内把话说满。
- **Results 陈述，Discussion 重组**。前者沿方法框架走，后者跳出框架挑最有意义的几条做对比与成因分析。
- **文献综述是找问题，不是列文献**。判断标准：把这一节单独给同行看，他能不能说出 gap 在哪。

## 实证稿的四个高频硬伤

1. **时点错位**。同一句「市场在公告时定价 X」，但效应 A 在事件前、效应 B 在事件后。两头的机制不可能相同，必须拆开讲，否则一句话包住两个相反的时间结构。查法：把每个关键效应按事件窗拆成 [−5,−1]、[0,1]、[0,3] 三段，看符号和显著性是否一致。
2. **测量误差没量**。文本编码、人工标注、LLM 分类这类变量，处理组往往只有个位数。查法：问「标签换一套，结论还成立吗」，要求作者做一次标签隐藏复核并报改判率。
   - **复核后系数上升不等于误差被校正**。复核常伴随处理组缩小（被改判的样本剔出回归），而系数上升可能只是「剔掉负值样本」的算术结果。要求作者在**复核后的同一批样本**上分别用初始编码与复核编码各估一遍、两个都报——只有这样才能把「改判率的贡献」和「样本缩小的贡献」分开。同一篇稿子里若同时出现「处理组从 13 条降到 7 条」和「系数从 5.76% 升到 7.51%」，默认先怀疑是后者。
   - **复核只校正假阳性，假阴性方向要单算。** 标签隐藏复核改判的是「编码说是、实质不是」那批；反向的「实质是、编码漏标」样本仍留在对照组，会把系数往反方向拉。查法：取实质层为处理类、披露层未标为处理类的样本，与对照组其余比均值。这批均值更低 → 真实效应被低估，复核后的系数只是下界。
     - 这一步的价值高于改判率本身："改判 7/15"是个精确度很差的点估计，而"漏标的 8 条方向相反"直接说明偏误方向，审稿人无法反驳。两者一个是精度、一个是方向，不能互相替代。
     - 报的时候把它与「剔掉负值样本的算术结果」并列摆出来，作为「系数为何升高」的两种竞争解释，而不是只报对自己有利的那种。
   - **个位数的处理组，比例本身不能当点估计**。7 条改判／15 条处理组，点估计 46.7%，Wilson 95% 区间是 25%—70%——半宽 25 个百分点。要把半宽压到 ±10% 需要约 96 条处理组，±15% 约 42 条。写「近一半被改判」会被外审当场算出区间打回。正确写法：报 `n/N` 加 95% CI，再补一句「要把区间压到 ±10% 需要约 96 条处理组，本文样本不支持这一精度」，把结论降级为提示性证据。**主动报区间比被审稿人算出来强**，而且它同时回答了「为什么不扩样本」这个必问项。
3. **描述性表挤占回归表**。样本筛选、变量定义、编码校验、口径对照这些是过程材料，不该跟主结果平起平坐。健康的比例是描述性表 2—3 个、回归表 6—10 个。
   - **稳健性写成段落等于没做**。八项检验挤在一段话里（「稳健性检验包括：仅年份 FE +5.82%、缩尾 +5.61%、剔除极端值 +5.49%……」），审稿人翻表看不到，就当不存在。逐项列成表：设定 / 系数 / p 值 / 样本量，一行一项。数据全都现成，只换排版——这是整份改稿清单里投入产出比最高的一处。
   - 同理，子样本分解、异质性若只有文字叙述、没有表，一并补表。补表时把「处理组样本量不足（N=12）、置信区间较宽」这类边界说明保留在原处，别因为做成了表就删掉。
4. **假设失守**。全局假设（如「物性为常数」）与后文核心模型冲突，却没作范围界定。查法：找假设 1/2/3，看后文是否废止、在哪一节废止、有没有写明。

## 摘要的数字取舍

摘要里每个数字要回答「效应有多大、有多可信」，不是「我是怎么算出来的」。

**该放**：主效应量级；显著性（p 或 t，二选一）；样本规模；一句话能说清的关键对比。

**不该放**：过程性计数（多少条堆积、几比几改判）；多窗口全套数字；稳健性检验的每个 p 值；分组样本量。

判断标准一句话：**这个数字，读者不看正文能不能理解它为什么重要？** 能就放，需要解释就不放。

一篇摘要放十二个数字，等于一个都没放。中文顶刊摘要可以一个数字都不放，学报类留三到四个合适。

**报长度用汉字数，别用观感。** 一段塞满数字与百分号的摘要看起来像 500 字，实际汉字常只有 300 出头（数字、拉丁字母、标点均不计）。给人下压缩指令前先数一遍，否则目标字数会定错一档。

## 过度降级也是病

改稿最常见的失败不是说得太大，是**降过头**：每个发现后面都跟一句「不成立」「不稳健」「不足以」，整篇读完读者不知道这稿子到底发现了什么，审稿人的下一句就是「那你的贡献是什么」。

判断法：数一数正文里「不稳健 / 不能 / 不足以 / 只能作提示」这类句子的密度。如果**每个发现段都以否定结尾**，就已经降过头了。

改法：每个发现段统一成「发现了什么 + 强度到哪」在前，「不支持什么」在后，一段最多一句。

> 高杠杆企业的大额补贴存在负向折价（交互项 −3.35%，p=0.016），替代窗口与缩尾下方向一致；置换检验只排除随机标签，不解决内生性。

这句和三段「该结果不稳健，只是方向性提示」信息量完全相同，但前者把结果留在了读者手里。

## 机制归因不能与理论方向相反

用某个理论解释一个结果之前，先核对那个理论的预测方向。典型错误：数据说「现金流**好**的高杠杆企业拿补贴后反应最负」，却用软预算约束（Kornai：亏损企业被救、因此不重组）来解释——那个理论预测的恰恰是现金流**差**的那批。

这类错配审稿人一定会问。两种处理：

- **换解释**，找预测方向一致的理论（如「本不缺钱还拿补贴 = 资金未被投向好项目」的效率信号反转）。
- **降级成谜**。写成「负效应集中在本不缺钱的企业，与现金流困境解释方向相反，现有理论不能直接解释」，比硬套一个反向理论安全得多。

同一段里如果出现「与 X 解释方向相反」紧接着「更符合 X」，那就是这个错。

## 用户要求「多跑几个显著」时

这个要求会以「换个角度」「再挖挖」「多跑几种设定」的形式提出，动机是觉得现有证据太弱。技术上永远做得到：换事件窗口、换因变量（CAR/BHAR）、换聚类层级（公司改行业，标准误变小）、剔子样本、换控制变量组合、按产权/规模/行业分组。二十个设定里，5% 水平本来就有约一个假阳性——那是概率，不是运气。

**不照做，但也不空讲道理，先给代价**：

- 它**降低**录用概率。审稿人识别 p-hacking 靠三件事：窗口数量与选择、控制变量来源说不清、多重检验未校正。改出来的显著会连带把稿子里原有的克制变成可疑。
- 稿子内部会自相矛盾。一篇通篇写「条件性证据」「探索性」的稿子突然多出三段稳健显著，审稿人第一反应不是「有新发现」，而是「前面那些为什么这么谨慎」。

**给正路，两条，都不在「换角度」上**：

1. **扩样本**。处理组只有个位数的稿子，任何显著都脆。这是唯一同时提升显著性与可信度的办法，也顺手解决审稿人第一个问题。
2. **预声明 + 全部报告**。先写死「我会跑这 N 个窗口、按 Bonferroni 校正」，然后全部报，包括不显著的。这样跑出来的显著才是真的。

真要加异质性检验，按**理论的预测方向**分组（哪个理论说该组更强），不是按「哪组跑出来显著」倒推。

## 输出：体检报告

```
## 判断
一句话：能投什么档 / 值不值得改 / 卡在哪一问

## 五问
1. 问题真伪：…（依据：引的第几篇）
2. 识别策略：…（是什么 / 缺什么）
3. 识别塌了剩什么：…
4. 增量一句话：…（能不能说清）
5. 可复现：…

## 结构
八段逐段过 / 不过，只列不过的

## 硬伤
按时点错位 / 测量误差 / 表比例 / 假设失守 逐条，带位置

## 语气
偏大还是偏小，证据是哪些句子

## 最小改动清单
按性价比排，3—5 条，每条给「改哪里 + 改成什么方向 + 预期效果」
```

## 与选刊的接口

体检结论直接决定选刊：

| 五问结果 | 能投 |
|---|---|
| 识别干净 + 增量清楚 | 学科主刊（CSSCI 中高位 / SSCI Q1—Q2） |
| 识别过关 + 增量局部 | CSSCI 低位 / Q3 |
| 只有相关性证据 + 事实清楚 | 北大核心 / Q4 / 普刊 |
| 识别塌了且描述性事实也薄 | 先改，别投 |

**投稿前必须先问「单位要求哪一档」**，再谈投哪本。档次定错，方向全错。分区体系与刊物对应关系见 `journal-paper-retrieval` skill 的分区口径一节。

### 先定方法论定位，再定刊

同一个结果可以包装成三种不同的论文，对应三类不同的刊。包装错，审稿人第一个问题就问偏。

| 定位 | 一句话 | 审稿人第一问 |
|---|---|---|
| **测度/指标类** | 我构建了新指标 X，X 有解释力 | 你的指标比现有的好在哪 |
| **测量误差类** | 既有文献用的指标错了近一半，错误方向可预测 | 误差多大、影响哪些结论 |
| **实质发现类** | 政策/事件对 Y 有什么效应 | 理论或政策含义是什么 |

判断法：看**贡献段写的是什么**。贡献写成「提供一套可复现的编码数据集 + 报出改判率」，那是第二类。当第二类投统计/方法类刊，对方问「你的测度创新在哪」，答「我证明旧测度错了」在审稿人听来是躲题。

还有一层常被忽略：**核心变量属于哪个学科的准则，就投哪个学科的刊**。核心解释变量是会计分类（政府补助准则）的稿子，内核是会计研究；投金融刊会被问「对资产定价有什么贡献」，投会计/披露类刊才问「对披露监管有什么含义」。按准则归属选刊，比按「主题看起来像金融」选刊准。

## 坑

- **别用「有没有创新」当诊断词**。它不可检验。换成「比引用的第 N 篇多了什么」。
- **别把语病当硬伤**。格式、错字、引用格式都是二审的事，识别和贡献才决定生死。
- **别只读摘要下判断**。摘要可以写得滴水不漏，问题都在研究设计和表里。
- **同一份数据拆多篇**要查是否为切香肠：每篇是否有独立研究问题，参考文献是否互引。
- **判断「表多不多」要分性质**。21 个表听起来很实证，如果 10 个是样本筛选与变量定义，实际回归只有 7 个，那是数据整理细、实证薄。
- **压稿丢的不只是字，还有附录。** 长稿压成期刊版后，正文里「本文公开两层编码数据集」这类承诺常在，兑现它的逐条明细表已经没了。grep `附录`／`Appendix`／`公开`／`详见`，每个承诺都要找到对应那张表。查法与补后必核的四个数见 `references/figure-and-appendix-defects.md`。
- **图要看像素，不能只看图注。** 图注可以完全准确而图仍然误导（封顶堆积未标、窗口子图被读成全样本、标注压在数据上）。十项清单与两条脚本级根因见 `references/figure-and-appendix-defects.md`。
