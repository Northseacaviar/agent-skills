# 按预期效应量选题

用户提「要能跑出显著性、得出鲜明结论」时，他要的不是保证显著（那只能靠造假），而是**一个效应本来就大的设计**。这份文件把「怎么在动笔前判断」落成可执行的检查。

## 一、前提：显著性来自设计，不是来自尝试

```
t ≈ 效应量 / 标准误
```

- **效应量**由选题决定：政策改不改规则、改得有多硬、结果变量离冲击有几层。
- **标准误**由样本量、窗口长度、对照组干净度决定。

所以选题阶段能干的两件事只有：挑大效应的冲击，挑信噪比高的样本。跑回归时换设定挑显著的那个不叫「跑出显著性」，叫 p-hacking——答辩和评审都会问稳健性，一问就露。

## 二、判断效应量：四个排序

| 维度 | 效应大 | 效应小 |
|---|---|---|
| 政策强度 | 直接改规则（准入、禁令、阈值、税收比例） | 引导、鼓励、表态、试点 |
| 传导层数 | 政策直接作用于结果变量（股价、减持量、分红率） | 隔三层（利率 → 融资成本 → 投资 → 股价） |
| 暴露度差异 | 横截面上有明显强弱（市值、分红率、质押率、出口占比） | 所有公司同向同幅 |
| 冲击时点 | 单日、可精确定位、有明确公告 | 渐进、无明确起点 |

**好效应的形状**：单调、量级大、方向符合理论。可作参照的实测例子：2024 年 4 月新「国九条」发布后四个月，指数按市值单调递减——上证50 +0.06%、沪深300 -0.97%、中证500 -7.41%、中证1000 -8.42%。四档排成一条线、极差 8.5pp，这种形状基本不会被审稿人说是噪音。

**坏效应的形状**：方向对但量级在噪音里、或只在某个子样本显著。前者是选题问题，后者要在开题前就想清楚样本够不够。

**传导链长 + 样本小 = 最难出结果**。地方性指标（某市民间利率、某县房价）配上本地少量上市公司，两层各削一半信噪比，叠加起来基本注定不显著。这类题看起来有特色、有地域优势，实际上是短周期项目里最大的坑。

## 三、数据可得性预检（一轮就能判死）

先验数据，再谈题目。判据只有一条：**今天能不能拿到可用的历史序列**。

| 看起来 | 实际要先确认 |
|---|---|
| 某个官方指数网站 | 是静态页还是 SPA。SPA 先拉 `performance.getEntriesByType('resource')` 看真实数据接口，再逐条 `curl` 探历史文件是否存在 |
| 数据平台有接口 | 接口是否还在维护。标注「暂停更新」的接口不能当选题地基 |
| 学术数据库 | 校内能不能登录、能不能导出。不能用「应该能」代替试一次 |

实测教训：地方金融指数官网首页有当期数值、也有「某指数 2013 年起日度」的描述，但把接口翻完只有另一条 LPR 的月度序列，指数本身没有历史文件；第三方接口标注停更。**宣传页上写「2013 年起日度」，不等于数据能下载。**

常用 A 股指数探针（baostock，免注册、本机可直连）：

```python
import baostock as bs, pandas as pd
bs.login()
rs = bs.query_history_k_data_plus("sh.000852", "date,close",
                                   start_date="2024-03-01", end_date="2024-08-15", frequency="d")
# sh.000016 上证50 / sh.000300 沪深300 / sh.000905 中证500 / sh.000852 中证1000
```

`Series.asof()` 的索引必须是 `DatetimeIndex`；直接把字符串日期传进去会报 `'<' not supported between instances of 'Timestamp' and 'str'`。建索引时写 `pd.to_datetime(df['date'])`。

## 四、20 分钟预检（开题前必做）

不要写开题报告再验证。直接跑：

1. 取政策前后各 1–3 个月的原始数据（指数或个股）。
2. 按预期机制分组（市值、分红率、行业），算各组累计涨跌幅。
3. 看三件事：**方向对不对、单调不单调、极差够不够大**。
4. 方向不对或极差小于 2pp，换题；否则再往下做识别策略。

预检输出要直接报给用户，包括「这个效应有一个必须解决的问题」——预检能发现的替代解释（同期其他政策、风格切换），就是后面正文里要做稳健性的地方。先说清，比写完被问出来强。

## 五、短周期论文（10–14 天）的时间表

论坛、会议、课程论文都落在这个量级。按这个顺序排，缓冲留两天：

| 天 | 干什么 |
|---|---|
| 1 | 选题预检 + 数据可得性确认 |
| 2–3 | 主回归 + 一个识别策略（三重差分 / 安慰剂期 / 窄窗口） |
| 4–7 | 写正文（引言在最后写） |
| 8–9 | 稳健性 |
| 10–11 | 格式、图表、汇报材料 |
| 12 | 缓冲 |

识别策略优先选：

- **三重差分**：政策前后 × 暴露度 × 机制变量。理论上有明确交互预测时最强，也最像论文。
- **安慰剂期**：拿同一月份在其他年份做同样对比，证明今年异常。成本最低，几乎必做。
- **窄事件窗口**：只在政策发布前后几天，避开后续其他政策。简单但容易被质疑预期效应。

## 六、主题挂靠

征稿常有固定主题清单，而题目未必严丝合缝。处理方式：

- 按**评审分组**选，不按字面匹配选——挂错组会被分给不熟的评委。
- 挂靠要能用一句话说通：「这个政策属于哪个主题的哪一类工具」。说不通就换题，不要硬凑。
- 交稿前跟用户确认一件他才有权决定的事：**是否署导师名**（影响分组与录用倾向），以及**截稿日**（征稿通知常只给会期，不给截稿）。
