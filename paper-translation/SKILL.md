# 英文论文中译交付

把一篇（或几篇）英文论文翻成**排版干净、能直接读的中文 PDF**。产出不是聊天里的译文段落，是文件。

## When to Use

- 用户发来 PDF 说「翻译一下发我」「翻成中文给我看」。
- 要把读过的英文文献做成中文精读稿给自己或同学看。
- 券商研报（投行 report）整篇中译、还要挂进 Zotero——先按 0.5 去水印，入库见 `zotero-library-ops`。
- 不适用：只要摘要/结论的中文摘要——那直接写摘要，不必走这套排版。

## 0. 先算体量，再定范围（省一轮返工）

先跑一遍字数统计，把结论摆给用户：

```python
import pymupdf, re
d = pymupdf.open(f)
words = len(re.findall(r"[A-Za-z][A-Za-z\-]+", " ".join(p.get_text() for p in d)))
```

一篇 45 页的实证论文约 1.3–1.8 万英文词，全译约 2 万字中文。**三篇就是六七万字**，一轮做不完——先交一篇让他验收格式，再按同规格续做，比闷头做三篇后被打回省得多。

默认范围（写进译文首页说明，别让用户猜）：

| 部分 | 处理 |
|---|---|
| 摘要、引言、制度背景、数据、识别策略、结果、机制、结论 | 逐段全译 |
| 数值表与图（表 1、图 1…） | **默认保留原图原表**：按 3.5 / 3.6 裁成图片插入，件文里照原编号引用（用户明确要求过“保留图表”，第一轮只给文字表格被打回） |
| 参考文献 | 不译（引用作者-年份照原文保留） |
| 网络附录、脚注里的文献对话 | 不译，或压成一句 |
| 公式 | 保留符号，写成 `ln(Land Price) = α₀ + …　(1)` 这种行内形式 |

用户若明确要「表格也翻」「要中英对照」，再改格式；否则按上表走。

## 0.5 券商研报：先去水印，再译

国内渠道流传的投行研报（花旗、高盛…）每页压了一层渠道水印，正文文字层本身是干净的。先去掉再译，否则裁图、插图会把水印带进成品。

跑 `scripts/remove_watermark.py <src> <dst>`：pikepdf 摘掉整页水印图、pymupdf redaction 清掉页脚隐形白字，跑完打印逐页文字长度对比。跑脚本用 `D:/Python/python`（这个解释器才有 pymupdf / pikepdf / python-docx / pywin32），先 `import pymupdf, pikepdf` 验一句再跑长脚本。

水印通常是两层，都得清：

- **整页背景图**：一张 4800×2700 的半透明 JPEG，十几页共用一个 xref。`get_image_rects()` 查不到它的落点（绘制时用了旋转/缩放），所以别按 rect 定位，按 `/Resources/XObject` 里 xref 相同的条目定位。光删资源名不够，内容流里那条 `Do` 也要摘掉，否则严格阅读器会报错。
- **页脚隐形文字**：3pt、白色、alpha=0 的一串乱码（渠道追踪串），`get_text()` 里能看见、肉眼看不见。用 redaction 删，别拿整页重排去凑。

判据（缺一条都不算干净）：逐页 `len(page.get_text())` 与原文对比，只允许藏隐形字那几页变短、且差值正好等于那串的长度；首页与任意正文页各渲一张 PNG 自己看，页眉 logo 与正文没被一起删掉。原件改名留档（`…_原始带水印.pdf`），成品 `…_去水印.pdf`，不覆盖原件。

券商研报的翻译取舍（与论文不同）：

- 正文 5 页 + 附录 7 页法律披露是常态。**法律披露不译**，封面说明与文末各申报一次（同「纯数学章节压成要点」的规矩），末尾补一句与内容相关的事实（如「过去 12 个月曾获投行服务报酬」）即可。
- 首页 `CITI'S TAKE` / `Summary` 与正文首段常逐字重复。译文合并处理，并在说明里写「原文第 N 页重复首段，已合并」——照抄两遍和偷偷删掉都算错。
- 原文偶有排版截断（单词被吃掉几个字母，如 `On RMB tion`）：按上下文还原，并在说明里点明。

## 1. 取文与切节

1. 抽全文落盘（别直接 print 到上下文）：`pymupdf` 逐页 `get_text()`，页间插 `===== PAGE n =====`，写到 `paper_text.txt`。
2. **表格会把上下文撑爆**：每页文本里一半是表格单元格。用「行长 ≥ 9 个词」过滤出散文行另存 `paper_prose.txt`，翻译只读这份。
3. 先 `grep -an '^[0-9]\. \|^Conclusion\|^References'` 拿节标题与行号，按节读、按节写，**不要一次读完整篇**。

## 2. 翻译写法

- 逐段写，不要跳段、不要合并成大段；原文一段 → 中文一段。
- 数字、单位、t 值、显著性、样本量一个不漏；原文括号里的作者-年份引用照抄（`Genesove and Mayer 2001`），不译成中文。
- 术语一经定下就全篇一致（如 LGFV＝地方融资平台、disposition effect＝处置效应），第一处出现给英文原词，之后只用中文。
- 不要加原文没有的评价、不要「值得注意的是」式的空转；原文的判断保留，原文的弱化（may / suggests）也保留，别顺手加强。
- 落成 markdown：`#` 标题、`##` 一级节（摘要、一、二…）、`###` 小节、`>` 放公式、`---` 放分隔。

## 3. 排版与导出

现成脚本：`scripts/md_to_docx_pdf.py`（python-docx 排中文 + Word COM 导 PDF）；
多篇共用一套排版时用 `scripts/build_translation.py <spec.json>`——spec 里给 md 路径、图目录与 `inserts` 锚点列表，
支持 `[[IMG:file|图注]]` 行内标记，跑完会打印未命中的锚点。

排版要点：

- **中文字体必须写 `w:eastAsia`**：只设 `run.font.name` 只改拉丁，中文会回落成默认字体（页面上就是「中文是宋体、数字是别家」的割裂）。
- **只给 `一、二、三…` 级标题分页**：每个 `##` 都 `add_page_break()` 会把「摘要」单独顶到新一页，留下大半页空白。
- 封面 + 作者 + 刊名卷期 + 收稿/录用日期 + **一段「翻译范围与取舍」说明**，与摘要同页。
- 正文 10.5pt / 行距 1.55 / 两端对齐；节标题用强调色（`#8E3B2E`）加粗。
- 导 PDF 走 Word COM：`app.Documents.Open(docx)` → `SaveAs(pdf, FileFormat=17)` → `ComputeStatistics(2)` 拿页数 → `Close(False)` → `Quit()`。
- 没有 Word / LibreOffice 时如实说导不出 PDF，只交 docx——不要拿 HTML 打印凑。

## 3.5 保留图表（用户说“图表也要”时）

不重排三线表、不折表格数字，而是**把原版表格裁成图片按原位插入**。

1. 定位：`page.get_text("blocks")` 找以 `Table N` / `Figure N` 开头的块，拿它的 `y0`；
   再找同页 `This table reports` / `This figure` 块的 `y1`，作为裁到底界。
2. 裁：`page.get_pixmap(clip=Rect(48, cap.y0-4, w-48, note.y1+6), dpi=200)`。
   图（Figure）标题在下方，起点要从版心顶部（约 y=70）起，否则只剩图注。
   **不要裁整页**：整页裁图里带着英文正文、页眉页码，插进中译本像贴了一张照片。判据很简单——图题块的 `y0`
   靠近页底（>200pt）说明图在它上方，起点取版心顶；图题靠近页首说明表在它下方，起点取图题 `y0-4`。
   裁完自己渲染看一眼，露出的第一行字若不是图/表本身就是裁错了。**末行也要看**：多 Panel 的表（A/B 两块）常在下缘被切掉，
   交付前逐张核「Panel 数、最后一行系数行是否完整」，不能只看第一行就对——上半截完整、下半截丢了的图最容易被当成成品。
3. 插图：python-docx `run.add_picture(path, width=Cm(W))`，W 取 `min(14.6, 20.0*w_px/h_px)`——
   **长表必须按高封顶**，否则一张表 24cm 高，整页被它占满且前后全空。
4. 图注：图片下一行居中、9.5pt 灰色，写「表 7　LGFV 购地（原文表）」这种中译短题；原文表注已在裁图里，不再重译。
5. 锚点插入：给每张图定一个正文锚句（如“表 2 报告回归结果”），遍历段落时 `if anchor in text` 就插在该段之后，
   并用 `_used` 集合防重；跑完打印**没命中的锚点**。
   **锚句必须是剥离 markdown 记号后仍存在的纯文本**：排版器先做 `re.sub(r"\*\*(.+?)\*\*", r"\1", text)` 再做包含匹配，
   所以写成 `**校准策略**是` 的锚句永远命不中（症状是跑完报一串「未插入」，但 DOCX 照样生成、看不出错）。
6. 译文里必须真的引用到每张表：原文有表 6、表 9 而译文没提，就补一句如实的引用（按表的分组结构写，不要编结论）。
7. 已知副作用（写进交付说明，别藏）：比剩余页高大的表会被 Word 推到下页，前一页下半留白。
   想少留白就把长表移到节末，别为了填满去缩图——缩到 10cm 宽的表在纸上读不清。

### 3.6 整页级的图表：走文末附录，不要嵌在段落之间

工作论文版的表格常整页排（一张表 20cm 以上），图也常占满一页。这类资产**不要**用锚点插在正文段落中间：

- Word 会把它整块推到下一页，上一页只剩几行字、下半全空，读起来像排版事故；
- 正文被硬生生切断，读者要往回翻两页才知道这段在讲什么。

改成：正文照常写「（见图 5）」或「表 7 报告……」，全部原图原表统一放到文末 `## 附：原文表与图` 一节，
用一行一个标记 `[[IMG:tab1.png|表 1　中国出口商动态统计（原文表）]]` 排下去，排版器逐张插入图片 + 图注。

附录里**每张图前不要再加加粗小标题**：图片被推到页底时，那小标题会孤零零留在上一页末尾，只剩标题和下一页的图注两头不靠。
图注已经写了「表 1／原文图 3」与中文短题，足够定位。

## 3.7 券商研报：先去水印，再谈翻译

研报常被转发站压过水印，通常是两层：

- **整页半透明大图**（渠道名 + 站点账号），同一张图出现在每一页；
- **页脚隐形白字**：白色、3–4pt、alpha=0 的追踪串，`get_text()` 里能抽出来但人眼看不见。

现成脚本：`scripts/remove_watermark.py <src.pdf> <dst.pdf> [--dry-run]`。

- 认图**不看 rect**：这类图常以非常规 CTM 贴，`get_image_rects()` 返回空，看着像没放。按「出现在 ≥60% 页面上的大图 xref」认。
- 删 `XObject` 之后必须把内容流里对应的 `Do` 一起摘掉，否则严格阅读器报操作符无效。
- 隐形字用 redaction 删（`fill=False` + `PDF_REDACT_TEXT_REMOVE`），别整页重排。
- 脚本结束会打印逐页 `len(get_text())` 的差：**只允许藏隐形字的那几页变短**，其余必须一字不差；再渲首页和一张正文页自己看，确认页眉 logo 与正文没被连带删掉。

**免责声明不逐字翻**（Analyst Certification / Important Disclosures 那 5–7 页法律文本）。在封面说明里声明一次、文末说明一次，同时提炼一句与内容相关的利益关系（如「过去 12 个月收取过投行服务报酬」）。把它算进正文，法律文本会把真正的分析挤成附录。

## 4. 交付前自检（渲染看图，不要只信脚本返回）

- 首页与一页正文导 PNG（`pymupdf` `get_pixmap(dpi=110)`）自己看：中文有没有方块、标题层级是否成立、有没有残留 markdown 符号。
- **markdown 斜体记号会漏进正文**：`*The Review of Financial Studies*` 这种行以内文出现时，按 `line.startswith('*') and line.endswith('*')` 的规则抓不到，星号原样印出来。排版前统一 `re.sub(r"\\*([^*\\n]+)\\*", r"\\1", text)`。
- 页数异常少（如 20 页以下翻完 45 页原文）通常是漏节：对照原文章节名逐节点一遍。
- 交付：`译文/<论文>_中译.pdf` + 同名 `.docx` 同目录；回复里给页数、字数、**哪些没译**，以及「另几篇按同规格续做」的说明。

## 坑

- **别把整篇论文塞进一次输出**：超长译文会中途降质、漏段。按节分批写文件（part1/part2 再合并）比一次写完稳。
- **正文里的中文引号**：译文用 `「」` 还是 `“”` 全篇统一，混用一眼就看出来。
- **原文的表格编号与正文对不上时以原文为准**，不要自己重编号；读者要对着英文 PDF 看表。
- 用户给的是**工作论文版**（首页写 NBER WORKING PAPER / First Draft）时，在封面注明版本与日期——和期刊版可能措辞不同，日后引用会踩坑。
- **年份按网络首发年标会错一年**：Crossref 的 `issued` 常是 OnlineFirst 年，正式卷期可能跨年（同一篇既是 2025 网发、又是 2026 年第 39 卷第 2 期 343–386 页）。用户发来出版方排版版时，以 PDF 页脚的卷期页码为准，并回头把索引/清单里的年份改过来。
- **纯数学章节压成「要点」必须两处申报**：封面说明写一句「第 N 节为推导，译为要点」，回复里再说一次。不申报就会被当成漏译。可压的判据是「这一节只有一阶条件、均衡定义、校准方程，没有可复述的经济含义」；带结果数字或机制的节不能压。
